# Лендинг Goulash.tech для владельца доставки на 1–5 точек

Тестовое задание. Страница собрана на токенах и UI-ките оригинального сайта (`css/tokens.css`, `css/ui-kit.css`, `css/header.css`), свои компоненты лежат в `css/landing.css` и `js/landing.js`.

## Открыть локально

```bash
python3 -m http.server 4173
```

Затем http://127.0.0.1:4173/

## Что внутри

Порядок блоков: первый экран → калькулятор-чек → как это работает → демо программы → клиенты → подключение → цена → вопросы → оффер и форма.

- Калькулятор связан с первым экраном, демо, блоком цены и формой.
- Демо: курсор-призрак, назначение курьера, приглашение гостя, отчёты, переключатель «Пик».
- Форма: проверка полей, загрузка, успех, ошибка с повтором. Заявка никуда не уходит, это демонстрация.
